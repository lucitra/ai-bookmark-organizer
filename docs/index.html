AI Bookmark Organizer

Save the current page, organize a chosen bookmark collection, and ask questions about links you already saved. Chrome’s on-device AI keeps bookmark processing on your computer.

Install locally

Until the Chrome Web Store listing is approved:

  1. 1

    Download and unzip the extension.

  2. 2

    Open chrome://extensions.

  3. 3

    Enable Developer mode.

  4. 4

    Select Load unpacked and choose the unzipped folder.

Review first

Useful on capture. Careful at scale.

Quickly save the active page, or open a persistent workspace for a folder-scoped scan. Every proposed category includes a reason and remains editable before any bookmark is moved.

Save and categorize

Save the current page into a chosen folder with an optional local AI category suggestion.

Scoped, resumable scans

Organize one folder or the full collection, pause safely, and resume from the latest completed checkpoint.

Ask your bookmarks

Get metadata-grounded answers with links back to the relevant bookmarks. Linked pages are never fetched or read.

Private by design

Active-tab and bookmark metadata is processed and stored locally. The extension contains no cloud AI, analytics, or background network service. Read the complete AI Bookmark Organizer Privacy Policy .

Release history and checksums · Security policy

Managed Chrome devices: An administrator may block unpacked extensions. The public download cannot override that policy; use the Chrome Web Store release once it is approved, and ask the administrator to allow its extension ID if required.
