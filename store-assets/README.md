# Chrome Web Store Assets

These assets use the AI Bookmark Organizer product mark and the Lucitra brand
palette:

- `icon-128.png` is also packaged under `icons/`.
- `screenshot-1.png` is the required 1280×800 product screenshot.
- `small-promo.png` is the required 440×280 promotional tile.

The editable SVG sources are committed beside the exported PNG files.

The icon source is `brand/logo.svg`, with the Chrome Web Store's recommended
transparent padding built into its view box.
