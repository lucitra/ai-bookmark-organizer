One local workflow

Capture, organize, and find things again.

The extension stays useful as a standalone bookmark tool. It does not require a Lucitra account or turn every saved link into a CRM record.

01

Save the current page

Choose a destination, add a category, or let Chrome’s local model suggest one. Only the active tab’s title and URL are read.

02

Organize with context

Select an explicit scope and describe the structure you want. Detail scales with collection size, including granular two-level folders for large libraries. Broad AI and investing themes split into useful leaves. Scans checkpoint locally and resume safely.

03

Ask your bookmarks

Search saved titles, URLs, folders, and organizer categories. Answers link back to sources and never pretend to read the page.

Human approval is the product

Nothing moves until the preview makes sense.

Local AI creates a collection-aware category plan, but the user owns the result. Every category is editable, every move is selectable, unresolved items are held for review, and the last apply can be undone.

PLAN

See the category structure before assignment begins.

REVIEW

Inspect metadata-grounded reasons and edit any category.

APPLY

Move only selected bookmarks into the chosen destination.

UNDO

Return the last applied set to its recorded folders.

Private by architecture

Your research stays under your control.

Standalone processing stays in Chrome. There are no analytics, remote code, host permissions, accounts, trackers, or linked-page collection. Optional agent access is separate and off by default.

ACTIVE TAB Title + URL

Read only after the user opens the extension to save a page.

BOOKMARKS Metadata + folders

Read locally; changed only after explicit review and approval.

LOCAL STORAGE Checkpoints + undo

Workspace state remains on the device and supports resumption.

AGENT ACCESS Off by default

Scoped, revocable, and provider-specific before metadata can leave Chrome.
