# Security Policy

## Supported versions

Security updates are provided for the latest release of AI Bookmark Organizer.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
[security@lucitra.ai](mailto:security@lucitra.ai) with:

- a clear description of the issue and its impact
- steps or a minimal example that reproduce it
- the affected extension version and Chrome version
- any suggested mitigation, if known

Lucitra will acknowledge a report as soon as practical, investigate it
privately, and coordinate disclosure after a fix is available.

## Release integrity

Official packages are published through
[GitHub Releases](https://github.com/lucitra/ai-bookmark-organizer/releases).
Each release includes SHA-256 checksums and GitHub build provenance. Release
assets and their associated tag are immutable after publication.
