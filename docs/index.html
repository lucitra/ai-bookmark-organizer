AI Bookmark Organizer

Scan your bookmarks, preview simple category folders, and apply the organization only when it looks right. Chrome’s on-device AI keeps bookmark content on your computer.

Download latest release View source

Versioned, checksum-verifiable releases from the public GitHub repository.

Install locally

Until the Chrome Web Store listing is approved:

  1. 1

    Download and unzip the extension.

  2. 2

    Open chrome://extensions.

  3. 3

    Enable Developer mode.

  4. 4

    Select Load unpacked and choose the unzipped folder.

Review first

Nothing moves until you approve it.

The extension reads bookmark titles and URLs only when you start a scan. It shows every proposed category before creating an AI Organized Bookmarks folder and moving the approved bookmarks.

On-device categorization

Uses Chrome Built-in AI when available, with no external AI API or subscription.

Complete preview

See the proposed destination for each bookmark before applying any changes.

No deletions

Creates category folders and moves bookmarks. It never deletes them.

Private by design

Bookmark information is processed and stored locally. Read the complete AI Bookmark Organizer Privacy Policy .

Release history and checksums · Security policy

Managed Chrome devices: An administrator may block unpacked extensions. The public download cannot override that policy; use the Chrome Web Store release once it is approved, and ask the administrator to allow its extension ID if required.
